## 13. AI 생성 규칙

이 문서를 참조해 설정이나 원고를 생성할 때 **반드시 지킬 것.**
아래 항목들은 실제 검토에서 반복 확인된 폭주 지점이다.

### 12-1. 총량 통제가 필요한 것

| 대상 | 규칙 |
|---|---|
| **depth 8–9 인물** | 자동 생성 금지. 기존 인물 목록을 먼저 조회하고, **작성자 승인 후에만** 추가한다 |
| **depth 10 인물** | 자율 생성 절대 금지. 작성자가 명시적으로 지시한 경우에만 |

§1의 "알려지지 않은 8–9급이 등장해도 세계관이 깨지지 않는다"는
**작가가 쓸 여지를 남겨둔 것이지, 생성 허가가 아니다.**

개별 사례는 위반이 아니어도 **누적되면 "세대에 몇 명"이라는 전제가 무너진다.**
서사적 위기를 돌파할 때 숨은 고수를 꺼내는 방식으로 해결하지 않는다.

### 12-2. 주화입마를 남발하지 않는다

> **AI가 다룰 수 있는 것은 2층까지다.**
> **3층(역행)은 작가가 배치하는 사건이며, AI가 판정으로 도출하지 않는다.**

3층은 극히 드문 파열이고 이야기의 결정적 장면이다.
계산으로 "이 인물은 3층입니다"라고 결론 내릴 대상이 아니다.

지킬 것:

- **감정을 느끼는 것을 어긋남으로 판정하지 않는다.** (§7-1)
- **행동의 격렬함을 층의 근거로 삼지 않는다.** 살초를 쓴다고 2층이 아니다.
- **태도가 부드러워진 것을 어긋남의 신호로 읽지 않는다.**
  "예전 같으면 벴을 텐데 그러지 않았다"는 대개 그냥 나이가 든 것이다.
- **심법을 참조하지 않고 판정하지 않는다.** 보편 기준은 존재하지 않는다.
- 2층 판정을 내릴 때는 §7-1의 판정 사례와 대조한다.

### 12-3. 수치를 계산하지 않는다

`sim.depth`와 `che.depth`는 **구간 표시이지 전투력 수치가 아니다.**

금지되는 것:

- 심과 체를 더하거나 평균 내는 것
- "심 8 + 체 7이 심 7 + 체 6보다 강하다" 같은 판정
- 임계값을 스스로 만드는 것 (`gap >= 3`, `fit >= 0.8` 등)
- 문파나 집단의 평균 depth를 계산하는 것

비교가 필요하면 **§8의 전적·상성 기반 서술**을 사용한다.

### 12-4. 미확정 항목을 채우지 않는다

§10의 목록은 **아직 정해지지 않은 것**이며, 빈칸을 채우라는 뜻이 아니다.

특히 주의:

- `fit`에 임의의 수치를 넣지 않는다. `null`로 둔다.
- `drift`의 누적·회복 규칙을 만들지 않는다.
- 탈신의 구체적 현상을 확정하지 않는다.
- **경맥·혈도·단전을 기의 통로로 서술하지 않는다.** 골조이지 배관이 아니다. (§5)
  → 기존 무협 문법(기·진기·내력·경맥 운행)으로 메우는 것이 **가장 흔한 위반**이다.
- **내공이 소모·회복된다고 쓰지 않는다.** 소모되는 것은 몸이다. (§5)
- **흡성대법 계통을 만들지 않는다.** 남의 마음은 가져올 수 없다. (§5)
- **깊이와 발현을 대응시키지 않는다.**
  "절정이면 검기, 초절정이면 검강" 같은 대응표를 만들지 않는다. §5 위반이다.
- 특이한 발현을 만들 때는 **반드시 그 근거를 함께 적는다.** 근거 없는 발현은 생성하지 않는다.

### 12-5. 예시를 분류표로 굳히지 않는다

§4의 "정파=올바른 마음 / 사파=욕망 / 마교=강함"은 **예시이지 분류표가 아니다.**

이 세 갈래의 변주만 반복 생성하면 세력이 아무리 많아도
심법의 정신 구조가 세 종류로 수렴한다.

- 세력마다 **다른 어휘와 다른 서술 형식**을 쓴다.
- 세 갈래 어디에도 잘 들어맞지 않는 심법을 의도적으로 섞는다.

### 12-6. `traits` 어휘를 무한히 늘리지 않는다

강직 / 곧음 / 불굴 / 굳센 의지 / 신념 / 완고 / 고집 — 이런 것들이
별개의 태그로 쌓이면 `traits`가 통제 불가능한 자연어 집합이 된다.

- **정규 어휘 목록 파일을 두고, 새 태그는 거기에 등록한 뒤 사용한다.**
- 기존 태그로 표현 가능하면 새로 만들지 않는다.
- 새 태그가 필요하다고 판단되면 **작성자에게 확인한다.**
- §9의 병합 작업은 세력 3~4개마다 반드시 수행한다.
