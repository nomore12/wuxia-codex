# 무협 세계관 프로젝트

하나의 무협 세계관을 구축하고, 그 안의 세력과 인물로 여러 편의 글을 쓰기 위한 저장소.

세계관은 여러 습작이 공유하는 자산이다. 한 번 제대로 지어두면 작품마다 회수된다.
따라서 이 저장소의 목표는 **모순 없이 확장 가능한 설정 체계**를 만드는 것이다.

## 초기 설정

클론 후 한 번 실행한다. 커밋 메시지에서 공동저자 표기를 제거하는 훅이 켜진다.

    git config core.hooksPath .githooks

## 문서 상태

모든 문서는 frontmatter에 `status`를 갖는다.

| 상태 | 뜻 | 위치 |
|---|---|---|
| `draft` | AI가 생성했거나 작업 중. **아직 사실이 아니다** | `drafts/` |
| `확정` | 작성자가 읽고 승인함. **여기에 어긋나면 오류** | `canon/` |

### 승격 규칙

**초안이 정전이 되려면 반드시 작성자가 읽고 승인해야 한다.**

이 게이트가 없으면 AI가 자기 생성물을 다음 작업의 근거로 삼으면서
세계관이 서서히 뭉개진다. **승격은 자동화하지 않는다.**

## 작업 단계

세력별로 4차에 걸쳐 진행한다.
**한 세력을 4차까지 끝내고 다음으로 가는 것이 아니라, 전 세력의 한 차수를 끝낸 뒤 다음 차수로 넘어간다.**

| 차수 | 내용 | 규칙 문서 | 상태 |
|---|---|---|---|
| 1차 | 무공·심법 **이름만** 나열 | `specs/1차작업규칙.md` | **완료** (44/44) |
| 2차 | 중복·오류 정리, origin 태그 검증 | — | **1차와 함께 완료** |
| 3차 | 한 줄 설명. 대표 무공의 초식 일부 | — | 다음 |
| 4차 | 심/체 배치, `traits`·`breaks_on` 추출 | — | 예정 |

## 진행 현황

### 완료

- **무공 체계 (L0)** — 심/체 이원 구조, 관문과 문턱, 힘의 정의, 주화입마 3층 구조
- **세력 목록** — 정파 25 · 사파 13 · 마도 7 · 무소속 1
- **천마신교 기원 확정** — 백련교 계열 미륵하생 신앙 + 불교 전복
- **세력별 차별화 지시** — 서술 형식 8종 배정
- **1차·2차 작업** — **44개 세력 전부 완료. 총 784개 항목.**
  origin 태그가 전부 부여되었고 `validate.py`가 매 세력마다 검증한다
- **도구** — `validate.py`(형식·금지어·중복) · `build_index.py`(색인 생성) ·
  `check_name.py`(색인 조회) · `build_notebooklm.py`(자료 묶음)
- **세계 층(L0)** — `drafts/연표.md`(앵커 일곱, 무림력) · `drafts/지리.md`(자리와 이동 시간)

### 수집 문서

1차 결과를 가로질러 정리한 것들이다. 다음 차수의 입력이 된다.

| 문서 | 무엇인가 |
|---|---|
| `drafts/전체요약.md` | 44개 세력의 지형. 형식·축·항목 수 |
| `drafts/미결모음.md` | 미결 158개를 해소 가능성별로 분류 |
| `drafts/세력관계.md` | 관계 단서 95줄을 종류 12가지로 |
| `drafts/시점수집.md` | 시간 서술 351개. 연표의 입력 |

### 다음

**3차 — 한 줄 설명과 대표 무공의 초식 일부.**

1. `specs/3차작업규칙.md` 작성 (`drafts/보완사항.md` §3이 초안)
2. 시험 삼아 몇 세력을 돌린 뒤 **검토**
3. 나머지 진행

> **먼저 돌린 몇을 반드시 검토한다.**
> 여기서 나온 문제는 나머지 세력에 그대로 반복된다.

## 이 세계관의 핵심 규칙

세부는 `canon/body-and-mind/00_INDEX.md`에 있다. 여기서는 자주 어기게 되는 것만 적는다.

1. **기(氣)라는 실체가 없다.** 내공은 몸 안을 흐르는 에너지가 아니라
   **마음을 힘으로 바꾼 것**이다. 氣·眞氣·內力·罡氣가 들어간 명칭을 쓰지 않는다.
2. **공인 등급표가 존재하지 않는다.** 삼류·일류·절정·화경 같은 체계는 없다.
   같은 현상을 문파마다 다르게 부른다.
3. **깊이가 무엇을 할 수 있는지 결정하지 않는다.** "절정이면 검기" 같은 대응은 없다.
4. **심/체 수치는 작가가 관리하는 좌표이지 세계 안의 눈금이 아니다.**
   본문에 노출하지 않는다. 대신 별호와 전적으로 표현한다.
5. **미확정 항목을 채우지 않는다.** `미확정사항.md`는 빈칸이 아니라 잠금이다.
