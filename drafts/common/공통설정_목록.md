# 공통 설정 목록과 진행 상태

이 폴더는 여러 문파에 걸쳐 적용할 공통 원칙과 일반적인 전통을 정리한다. 각 문서의 적용 범위를 따르며, 정파 문파의 규칙을 다른 세력에 자동으로 적용하지 않는다.

## 상태 기준

- **완료:** 합의한 범위의 공통 원칙을 정리하고 문서로 저장했다. 정전 승격이나 모든 예외의 해소를 뜻하지 않는다.
- **미완료 · 예정:** 다음에 다루기로 했으나 아직 공통 설정을 확정·저장하지 않았다.
- **미완료 · 검토 후보:** 대화에서 검토 대상으로 언급했으나 독립 항목으로 다룰 범위와 채택 여부가 정해지지 않았다.
- **문파별 설정:** 공통 규칙으로 통일하지 않기로 한 사항이다. 공통 설정의 미완료 작업으로 세지 않는다.

목록의 미완료 항목은 앞으로 논의할 주제이며, 그 제도나 명칭을 세계관에 도입하기로 확정했다는 뜻이 아니다. 새 주제는 논의에 따라 추가한다.

| 미완료 · 검토 후보 | 세가의 항렬과 조직 | 혈연 항렬, 가주 계승, 방계·객경의 자리 | 위와 같은 이유로 제외. 문서 없음 |
| 미완료 · 검토 후보 | 문파의 실무 조직 | 살림·접객·교육·경비 등 업무 분담과 담당 직책 | 장문인·장로 이외의 공통 체계가 필요한지부터 검토. 문서 없음 |

## 완료 문서의 세부 확인

### 정파 문파의 항렬과 조직

- [x] 적용 대상과 비적용 세력의 구분 — 사승 항렬을 쓰는 정파 문파에만 적용
- [x] 골격은 공통, 명칭 층은 계열별로 교체 (장문인·방장·방주·가주)
- [x] 항산파의 「대(代)」와 제자 세대 번호의 충돌 회피
- [x] 사승 관계에 따른 항렬과 문파 전체의 입문 선후
- [x] 장문인 바로 아래 항렬 전체를 일대제자로 정의
- [x] 장문인 취임 시 일대·이대·삼대 번호 재부여
- [x] 세대 번호는 장문인에서 아래로만 내려간다. 같은 항렬·윗항렬에는 번호를 붙이지 않는다
- [x] 예외 계승이 남기는 항렬과 직위의 어긋남
- [x] 건너뛴 항렬의 장로 자격 — 자격은 유지하고 인정은 문파별 절차에 맡긴다
- [x] 정식 입문·문적 등록 시점과 동시 입문자의 순서
- [x] 입문 자격 및 승인 절차를 문파별로 설정
- [x] 기본 사승 호칭과 성별에 따른 사용 범위 — 여성형을 따로 두지 않은 근거를 문서에 남겼다
- [x] 사조 항렬과 그 위의 호칭 — 「조」가 한 대 위, 「태」가 다시 한 대 위
- [x] 아랫사람은 이름으로 부른다. 제자·사질·사손은 가리키는 말이다
- [x] 장문인 계승 후보의 항렬 조건과 예외 계승 원칙
- [x] 장문인 선출 방식은 문파별 전통에 위임
- [x] 장로 자격 및 문파별 인정·임명 절차
- [x] 항렬은 자격, 인정은 성취와 평판을 함께 본다. 기준선은 두지 않는다
- [x] 장로 직위가 강함을 보증하지 않는다
- [x] 장문인과 장로의 관계·역할·일반적인 직위 호칭
- [x] 장로 회의의 권한과 요청 범위를 문파별로 설정
- [x] 공식 규칙과 실제 운영이 다를 수 있음을 명시
- [x] 장로의 종신·자진 퇴임을 일반적인 전통으로 정리
- [x] 퇴임 장로의 호칭과 권한을 구분
- [x] 전임 장문인의 장로 임명 및 자유로운 호칭

### 해검지와 출입 예법

- [x] 기본값은 무기를 지닌 채 들어가는 것이며 해검은 예외다
- [x] 해검지는 남이 인정해야 서고 자칭으로는 서지 않는다
- [x] 인정의 범위가 고르지 않다는 것과 그것이 세력 관계라는 것
- [x] 요구를 받은 쪽의 세 갈래와 거절이 적대가 아니라는 것
- [x] 맡긴 무기의 보관·반환 의무와 본뜨기 금기
- [x] 요구하지 않는 자리 — 급보·부상·상례, 회담과 비무
- [ ] 어느 문파가 해검지를 가졌는가 — 세력 문서를 손볼 때 정한다.
- [ ] 누가 누구의 해검지를 인정하는가 — 인정의 지도.
- [ ] 사파·마도에 이 틀이 어떻게 걸치는가.
- [ ] 무기가 아닌 것(암기·독)을 어디까지 볼 것인가.

### 남겨둔 후속 쟁점 — 정파 문파의 항렬과 조직

- [ ] 예외 계승에서 일대제자들의 동의를 확인하는 기준 — 전원 동의 등 구체적인 기준은 미정이다.
- [ ] 재입문·스승 변경 등 예외 상황의 처리와 호칭 — 필요할 때 별도로 논의한다.
- [ ] 파문 이후의 호칭 — 문규와 문하 이탈을 다룰 때 함께 검토할 수 있다.
- [ ] 소림의 산문·속가를 입문 선후에서 어떻게 다룰 것인가 — 한 줄로 세우지 않을 가능성이 있다.
- [ ] 불문 문파의 세대 번호 명칭과 계율 호칭의 범위 — 소림·아미·항산 각 문서에서 정한다.
- [ ] 항산파가 제자 세대를 부르는 말 — 항산파 문서에서 정한다.

## 문파별로 정하도록 남긴 사항

아래 항목은 공통 설정을 빠뜨린 것이 아니라, 문파별 전통과 사정에 맡기기로 한 사항이다.

- 입문 자격, 의식의 형식, 제자 수용과 문파 가입의 승인 권한·절차
- 장문인 후계자의 선택 주체와 구체적인 선출 방식
- 장로의 인정·임명 절차, 그리고 성취와 평판을 어느 만큼 보는가
- 장로 회의의 자문·의결 범위와 장문인의 요청 범위
- 공식 규칙과 실제 권력 관계·관행의 차이
- 일반적인 전통과 다른 장로의 임기·퇴임 규칙, 해임 여부와 절차
- 퇴임 장로의 별도 예우와 권한
- 전임 장문인을 부르는 호칭과 개인 관계에 따른 차이

## 갱신 방법

1. 새 주제를 논의하기로 하면 대항목 목록에 추가하거나 검토 후보를 예정으로 바꾼다.
2. 내용을 합의하고 문서로 저장한 뒤 완료로 바꾸고 실제 문서 링크를 연결한다.
3. 완료 항목에도 남은 쟁점이 있으면 별도 체크 목록으로 표시한다.
4. 문파별로 정하기로 합의한 사항은 공통 설정의 미완료 항목에서 구분한다.
5. 기존 결정을 바꾸면 해당 설정 문서와 이 목록을 함께 갱신한다.
