# 세력 관계 단서

> 세력 문서를 만들면서 나온 **관계의 실마리**를 모은다.
> 여기서 관계를 확정하지 않는다. 흩어지지 않게 붙들어 두는 것이 목적이다.
> 세력 작업이 끝난 뒤 이 문서를 근거로 관계망을 짠다.

| 세력 A | 세력 B | 단서 | 출처 |
|---|---|---|---|
| 소림사 | 천마신교 | 같은 경전을 읽고 갈렸다. 대칭 구조 | canon/세력목록.md |
| 하북팽가 | 사천당가 | 오대세가이면서 무공의 성격이 정반대 | 하북팽가.md |
| 아미파 | 사천당가 | 같은 사천. 가늘고 정확한 것을 쓴다는 점이 닮았다 | 아미파.md |
| 아미파 | 소림사 | 같은 불가이나 종파가 다르다 (선종 / 화엄·보현) | 아미파.md |
| 무당파 | 소림사 | 같은 것을 다르게 부르는 자리가 있는가 | 무당파.md |
| 천마신교 | 혈교 | 갈려 나갈 때 어느 겁의 것을 가져갔는가 | 천마신교.md |
| 사천당가 | (미정) | 당가에서 흘러나간 독을 쓰는 자들 | 사천당가.md |
| 청성파 | 사천당가 · 아미파 | 같은 사천 셋. 겨룸의 거리가 각기 다르다 — 보낸다 / 다가간다 / 기다린다 | 청성파.md |
| 청성파 | 무당파 | 같은 도가이나 층이 다르다 (도덕경·장자 / 천사도·의례) | 청성파.md |
| 청성파 | 화산파 | 지형을 무공에 들인 방식이 반대다 (험險 / 그윽함幽) | 청성파.md |
| 종남파 | 화산파 | 같은 섬서. 종남산과 화산은 지척이다 | 종남파.md |
| 종남파 | (미정) | 청운검법이 한때 다른 문파로 넘어갔다가 되찾아왔다 — 그 문파가 어디인가 | 종남파.md |
| 곤륜파 | 무당파 · 청성파 | 같은 도가이나 층이 다르다 (사상 / 교단·의례 / 신화·아득함) | 곤륜파.md |
| 곤륜파 | 사천당가 | 같은 외부시선형이나 모르는 이유가 다르다 (감춤 / 멂) | 곤륜파.md |
| 공동파 | 무당파 · 청성파 · 곤륜파 | 네 번째 도가. 사상 / 교단 / 신화 / 문답(황제·광성자) | 공동파.md |
| 공동파 | 하북팽가 | 같은 단일특화형이나 축이 다르다 (무엇을 베는가 / 어떻게 닿는가) | 공동파.md |
| 점창파 | 하북팽가 · 공동파 | 세 번째 단일특화형. 대상도 동작도 아닌 시간(몇 수인가)이 축 | 점창파.md |
| 점창파 | 화산파 · 종남파 · 청성파 | 네 번째 검법 문파. 수렴 / 파편 / 분산 / 무(無) — 검 외에는 아무것도 두지 않는다 | 점창파.md |

## 아직 단서가 없는 조합
