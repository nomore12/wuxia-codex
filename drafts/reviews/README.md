### 맡길 때 지킬 것

**「이 문서 안에서만 판단하라. 일반적인 무협 상식으로 빈칸을 메우지 말라」**를 반드시 명시한다.

그리고 아래 셋을 함께 적는다. `AGENTS.md`에 이미 있으나 도구가 안 읽을 수 있다.

- 다른 도구의 보고서를 참조하지 않는다
- 숫자는 직접 센다. 지시서에 적힌 수치도 그대로 믿지 않는다
- 문서가 「의도적으로 비워둔 것」이라 밝힌 자리는 결함으로 세지 않는다

**받은 것을 그대로 반영하지 않는다.** 결론보다 목록이 값이 크다.
