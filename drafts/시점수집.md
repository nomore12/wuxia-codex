# 시점 수집 — 연표 이전

> **아무것도 정하지 않았다.** 문서가 이미 말한 것을 옮겼을 뿐이다.
> 여기서 시점을 확정하지 않는다.

> 이 문서는 세력 문서에서 옮긴 것을 담는다.
> **세력 문서를 고치면 여기도 함께 본다.**

44개 문서를 전수로 훑어 **시간 서술 351개**를 옮겼다. 연도도 순서도 정하지 않았고, 어긋나 보이는 자리는 §4에 표시만 했다.

**44개 세력 전부에 시간 서술이 있다.** 연표와 무관하게 서 있는 세력은 하나도 없다.

| 절 | 무엇을 모았는가 |
|---|---|
| §1 | 본문의 시간 서술 **351개** — 이 문서의 본체다 |
| §2 | 상대 순서만 정해진 것 **40개** |
| §3 | 나이·대(代)·수가 명시된 것 |
| §4 | 서로 어긋날 수 있는 것 **12개** |
| §5 | 명시적 미결 **17개** |
| §6 | 앵커 후보 **14개** |

## 2. 상대 순서만 정해진 것

**「A가 B보다 먼저」만 있고 절대 시점이 없는 것들이다.**
연표를 짤 때 이 순서가 제약이 된다. 순서를 새로 정하지 않았고, 문서가 말한 것만 옮겼다.

| 천마신교의 흑련이 먼저 → 혈교가 적련을 맞대어 지었다 | 천마신교 · 혈교 | 혈교 무공 비고 |
| 만금표국 → 은표 고안 → 강남으로 내려가 만금전장을 엶(이름을 가져감) → 전장이 커지며 표국이 마름 | 만금표국 · 만금전장 | 양쪽 개요 |
| 소림 쪽이 몸을 다스리는 법의 이름을 먼저 차지 → 황보의 것이 자리를 잡지 못함 | 황보세가 · 소림사 | 황보 개요 |
| 숭산파가 지니고 있었다 → 소실(소림)로 넘어갔다 **(숭산의 주장이며 절은 말이 없다)** | 숭산파 · 소림사 | 숭산 개요 |
| 무림맹이 결성·해체를 몇 차례 되풀이 → 그 뒤로 아무것도 세워지지 않음 → 사도련만 서 있음 | 사도련 · (무림맹) | 사도련 개요 |
| 녹림산의 일이 먼저 → 그 뒤로 산에 든 무리를 녹림이라 부름 | 녹림맹 | 녹림 개요 |
| 미륵을 기다리던 자들 → 기다리지 않기로 함(천마신교) → 그중 한쪽이 갈라짐(혈교). 배화교는 이 순서 밖에 있다 | 천마신교 · 혈교 · 배화교 | 배화교 개요 |

### 순서를 정할 수 없다고 문서가 못박은 것

| 세력 | 무엇이 | 근거 |
|---|---|---|
| 아미파 | **고리에는 처음이 없다.** 회향이 처음으로 되돌리므로 그 앞이 있을 수 없다 | 개요 · 어디가 처음인지 |
| 형산파 | 회안결은 도관과 절 **양쪽 다 제가 먼저라 한다** | 심법 비고 |
| 녹림맹 | 같은 무공의 이름 둘 중 **어느 쪽이 먼저인지 따지는 자가 없다** | 개요 |
| 화산파 | 심종이 언제부터 이끌었는지 **문파 안에서도 말이 갈린다** | 노선 |
| 개방 | 같은 무공을 낙양과 개봉이 **각기 다른 사람에게서 나왔다 한다** | 전해지는 방식 |
| 무당파 | 갈래가 끊긴 일곱은 **어느 심법에서 나왔는지 무당 안에서도 말이 갈린다** | 무공 |

## 3. 나이·대(代)·수가 명시된 것

### 절대 기간이 적힌 것 — 넷뿐이다

| 세력 | 원문 | 무엇의 나이인가 |
|---|---|---|
| 소림사 | 천 년을 지나는 동안 이만큼 쌓인 곳이 없다 | 절 |
| 숭산파 | 같은 산에 천 년을 쌓은 절이 있으므로 | 절 (소림을 가리킨다) |
| 하북팽가 | 도 하나를 천 년 쥐면 도 하나로 못 할 일이 없다 | 집안 |
| 혈교 | 열 해 전에 본 자가 말하는 것과 지금 겪은 자가 말하는 것이 다른데 | 목록의 변동 주기 |

**「천 년」이 세 번 나오고 그중 둘은 같은 절을 가리킨다.** 나머지 하나가 팽가다. §4를 볼 것.

### 대(代)를 쓰는 세력 — 열여섯

**한 대의 길이가 정해지지 않으면 이 열여섯이 서로 맞물리지 않는다.**

| 세력 | 대를 어떻게 쓰는가 |
|---|---|
| 항산파 | **1대 ~ 4대.** 세력 가운데 유일하게 대에 번호가 붙어 있다. 5대 자리는 비어 있다 |
| 남궁세가 | 판이 종가 12 · 지파 8 · 옛본 8. **몇 대까지 갈렸는지는 미결** |
| 황보세가 | 조전신공 — **몇 대째인지 이제 세지 않는다** |
| 개방 | 죽고 나면 **두 대 만에** 이름이 흐려진다. 대를 이어 지키는 건물이 없다 |
| 해남파 | **한 대에** 문하가 스물을 넘긴 적이 드물다 |
| 흑사방 | 갈라진 것이 **몇 대 전인가** — 미결 |
| 곤륜파 | 중원이 하는 말은 대개 **몇 대 전** 이야기다 |
| 혈영문 | 이 이치를 **어느 대에** 정했는지는 전하지 않는다 |
| 사천당가 | 시집간 딸이 가져간 것은 **그 대에서** 끝나야 한다 |
| 제갈세가 | **대를 이을 때마다** 머리가 전해졌는지 새로 확인한다 |
| 산서석가 | 대를 이어 날을 벼려 왔다. 아비가 아들 옆에 서서 같이 두드린다 |
| 황산파 | 대를 이어 앞서 걷는 일을 해 왔다 |
| 만금표국 | 그 일 하나로 대를 이어 왔다 |
| 장강수로채 | 자리를 잡고 대를 이어 앉아 있다 |
| 황보세가 | 산동에서 대를 이어 몸을 단련해 왔다 |
| 천마신교 | **대를 거듭할수록 갈래는 줄어든다** (겁을 대로 세는 자리) |

> **개방과 황보가 정반대다.** 개방은 두 대면 이름이 흐려진다 하고, 황보는 몇 대째인지 세지 않는다 한다.
> 하나는 대가 짧아서 못 세고 하나는 대가 길어서 안 센다.

### 수(數)가 붙은 것

| 세력 | 수 | 그 수가 맞는가 |
|---|---|---|
| 녹림맹 | 열여덟 채 | **맞은 적이 드물다.** 어떤 해에는 스물, 어떤 해에는 열둘. 세는 자가 없다 |
| 장강수로채 | 열여덟 채 | **센다.** 맞지 않는 해에는 문서를 고친다 |
| 개방 | 항룡십팔장 | 곳마다 다르게 센다. 스물이라는 분타, 열둘이라는 분타 |
| 녹림맹 | 박도십팔식 | — |
| 소림사 | 칠십이절기 | **일흔둘은 항목의 개수가 아니라 체계의 이름이다.** 나머지 자리는 채우지 않았다 |
| 아미파 | 열 서원 | 고리이므로 순서가 없다 |
| 천마신교 | 청양 12 → 홍양 7 → 백양 0 | 겁마다 줄어든다 |
| 제갈세가 | 팔진 여덟 · 팔진도 예순넷 | 사람 수다 |
| 항산파 | 1~4대 | 5대는 비어 있다 |
| 점창파 | 한 수 · 두 수 · 세 수 | 시간이 축이나 연표와는 무관하다 |

### 나이가 명시된 인물 조건

| 세력 | 원문 | 무엇 |
|---|---|---|
| 철혈문 | 대개 **마흔**을 넘기지 못하고 손을 놓는다 | 문하의 수명 |
| 채화방 | 같은 자가 **두 해**를 넘겨 이 일을 하는 경우가 드물다 | 무리의 지속 |
| 진주언가 | 치는 법을 익히기 전에 **몇 해**를 맞으며 몸을 다진다 | 수련 기간 |
| 해남파 | 한 대에 문하가 **스물**을 넘긴 적이 드물다 | 문하의 규모 |
| 흑풍채 | 채에 남은 자가 **아홉**이라는 말이 있고 **열둘**이라는 말이 있다 | 현재 인원 |
| 청성파 | 상청정 — 산에 든 **첫해**에 받는다 | 수련 시기 |
| 항산파 | 호국결 — 산에 든 **첫해**에 받는다 | 수련 시기 |

### 이동·지연에 걸린 기간

| 세력 | 원문 |
|---|---|
| 곤륜파 | 돌아오는 데 **몇 해**가 걸린다 · 편지가 오가는 사이에도 몇 해가 지난다 |
| 해남파 | 바람이 맞지 않으면 **며칠**, 철이 어긋나면 **달**을 넘긴다 |
| 만금표국 | **열흘**이면 갈 것을 **보름**에 간다 |

| 살막 | **사흘**을 따라붙던 자를 보았다 |
| 암향각 | **사흘 전**이었다고 했다가 **그날 밤**이었다고 고친다 |

## 4. 서로 어긋날 수 있는 것

**판단하지 않았다. 표시만 한다.**
아래는 연표를 짜기 시작하면 부딪칠 자리이며, 지금 해소하지 않는다.

| # | 어긋날 수 있는 자리 | 걸린 세력 | 무엇이 부딪치는가 |
|---|---|---|---|
| 1 | **국가가 무언가를 끊은 사건이 둘이다** | 태산파 · 배화교 | 태산은 「천자의 예가 끊겼다」, 배화교는 「밖에서 온 가르침을 함께 쓸어낸 일」. 둘 다 국가가 끊은 사건이고 둘 다 그 뒤로 쇠락했다. **같은 때인가 다른 때인가** |
| 2 | **「천 년」이 두 집단에 각각 붙어 있다** | 소림사 · 숭산파 · 하북팽가 | 소림과 숭산의 천 년은 같은 절을 가리켜 맞물린다. 팽가의 천 년은 별개다. **정하면 절과 세가가 같은 나이가 된다** |
| 3 | **관(官)은 보류인데 여섯 세력이 관에 시간축을 걸고 있다** | 태산파 · 항산파 · 모용세가 · 하북팽가 · 녹림맹 · 만금표국 · 배화교 | `canon/세력목록.md`가 관·조정을 「지금은 다루지 않는다」로 보류했는데, 위 일곱의 내력이 관·군·천자·관도에 걸려 있다. **연표를 짜려면 보류를 건드리게 된다** |
| 4 | **「열여덟」이 세 곳에 있고 세는 방식이 다르다** | 녹림맹 · 장강수로채 · 개방 | 녹림은 언제 세어졌는지 모르고, 수로채는 해마다 고쳐 세고, 개방은 곳마다 다르게 센다. **같은 수가 세 곳에 있는 것이 우연인가** |
| 5 | **「몇 해 전」이 두 곳에 있고 재는 자가 다르다** | 흑풍채 · 곤륜파 | 흑풍채의 「몇 해 전 새 길」은 채가 직접 겪은 일이고, 곤륜의 「몇 해 전」은 중원이 소식을 들은 시점이다. **같은 단위가 아니다** |
| 6 | **소실로 넘어갔다는 주장에 상대가 없다** | 숭산파 · 소림사 | 숭산은 넷이 소실로 넘어갔다고 말하고 절은 말이 없다. **소림 문서에는 이 이야기가 아예 없다** |
| 7 | **사방이 갈라진 시점이 양쪽 다 열려 있다** | 흑사방 · 백사방 | 흑사방은 「몇 대 전인가」를 미결로 두었고, 백사방은 「나온 것인지 밀려난 것인지」를 미결로 두었다. **두 문서가 같은 사건을 각기 다른 방향으로 비워두었다** |
| 8 | **「한때 컸다」가 넷인데 네 가지가 다 다르다** | 태산파 · 종남파 · 패도문 · 황산파 | 태산은 잃었고, 종남은 비다시피 했고, 패도문은 처음부터 크지 않았고, 황산은 잃을 것이 없었다. **넷을 한 연표에 놓으면 「쇠락」이 네 가지 뜻이 된다** |
| 9 | **혈교의 분리 시점이 두 갈래로 읽힌다** | 천마신교 · 혈교 | 「갈라진 것이 가장 최근」이라 하고, 「열 해 전에 본 자와 지금 겪은 자의 말이 다르다」고도 한다. **분리가 열 해 안쪽인지 그보다 훨씬 전인지 문서가 말하지 않는다** |
| 10 | **은표가 언제부터 널리 쓰이는지가 세 문서에 걸쳐 다르게 읽힌다** | 만금표국 · 만금전장 · 용문표국 | 만금표국은 「줄고 있다」(진행 중), 만금전장은 「커질수록 준다」(진행 중), 용문표국의 장부에는 은표가 없다. **셋의 시제가 맞물리지 않는다** |
| 11 | **대(代)를 재는 방식이 정반대인 둘이 있다** | 개방 · 황보세가 | 개방은 두 대면 이름이 흐려진다 하고 황보는 몇 대째인지 세지 않는다 한다. **한 대의 길이를 정하면 둘 중 하나가 어색해진다** |
| 12 | **아미 문서가 세 세력의 시간 결손을 이미 대비해 두었다** | 아미파 · 무당파 · 천마신교 | 「무당은 과거를 잃었고, 천마신교는 미래가 없고, 아미는 순서를 모른다」. **이것은 어긋남이 아니라 정리된 대비다.** 연표가 셋 중 하나를 메우면 이 대비가 깨진다 |

### 심각해 보이는 셋

1. **#3 — 관(官)이 보류인데 일곱 세력이 관에 걸려 있다.**
   태산의 봉선, 항산의 변방 요새, 모용의 연(燕), 팽가의 관군 제식 도, 녹림의 관병, 만금표국의 관도, 배화교의 살보. 연표의 앵커 후보 가운데 가장 많은 문서가 걸린 것이 전부 관 쪽이다. **보류를 유지한 채로 연표를 짤 수 있는지부터 정해야 한다.**

2. **#1 — 국가가 끊은 사건이 둘이다.**
   태산과 배화교가 각기 다른 문서에서 「국가가 끊었고 그 뒤로 쇠락했다」를 말한다. 하나로 합치면 앵커가 하나 생기고, 둘로 두면 앵커가 둘이 된다. **어느 쪽이든 연표의 뼈대가 달라진다.**

3. **#2 — 「천 년」이 소림과 팽가에 각각 붙어 있다.**
   소림의 천 년은 「그럼에도 이만큼 쌓인 곳이 없다」의 근거이고, 팽가의 천 년은 「도 하나로 못 할 일이 없다」의 근거다. 둘 다 최고(最古)를 주장하는 자리에 쓰였다. **한 세계에 천 년짜리가 둘 있어도 되는지가 정해져야 한다.**

| 소림사 | 산문·속가 분열의 유래와 현재 관계 | 위와 같은 묶음 |
| 용문표국 | 노첩이 넘어간 일이 언제였고 어디로 갔는가 | §1에 「실제로 베껴 간 자가 있었다」로 사건만 있다 |
| 용문표국 | 표를 잃은 적이 있는가, 있다면 어떻게 물었는가 | 사건의 유무 자체가 미정 |
| 종남파 | 문파가 비다시피 했던 시절에 무슨 일이 있었는가 | §4-8 「한때 컸다」 넷 중 하나 |
| 철혈문 | 받으러 가는 일을 언제부터 맡았는가 | 사도련 성립 이후여야 한다 (§2 세력 사이) |
| 태산파 | 천자의 예가 언제 왜 끊겼는가 — 연표를 건드리므로 미룬다 | **§4-1 · §4-3 · §6 앵커 후보의 한복판** |
| 태산파 | 예를 거들던 자리가 문파가 되기까지의 과정 | §2 태산 내부 순서 |
| 하북팽가 | 출사·재야 분열의 유래와 현재 관계 | 「문파 분열의 유래 다섯」 묶음 |
| 형산파 | 절 쪽 문하가 언제 왜 끊겼는가 — 연표를 건드리므로 미룬다 | §6 앵커 후보 |
| 화산파 | 검종·심종 분열의 내력과 현재 세력 관계 | 「문파 분열의 유래 다섯」 묶음 · §2 순서 미정 |
| 흑사방 | 갈라진 것이 몇 대 전인가 — 백사방 문서와 맞물린다 | **§4-7 · §3 한 대의 길이** |
| 흑풍채 | 새 길이 언제 났고 누가 냈는가 | §4-5 · 「몇 해 전」이 유일하게 특정 가능한 사건 |

> **열일곱 중 넷이 「연표를 건드리므로 미룬다」거나 「몇 대 전인가」로 적혀 있다.**
> 태산 · 형산 · 흑사방 · 남궁이며, 이 넷은 연표 없이는 답이 나오지 않는다.

## 6. 앵커 후보

**정하지 않는다. 후보만 표시한다.**
「걸린 문서」는 그 사건을 직접 언급하거나 그 사건에 내력이 닿아 있는 세력의 수다.

| 후보 사건 | 걸린 문서 | 어디에 적혀 있는가 |
|---|---|---|
| **관(官)이 무언가를 끊은 일** — 태산의 봉선과 배화교의 쓸어냄이 같은 때인지가 여기서 갈린다 | 7 — 태산파 · 배화교 · 항산파 · 모용세가 · 하북팽가 · 녹림맹 · 만금표국 | 각 개요 · `canon/세력목록.md` 보류 항목 |
| **은표가 나온 일** — 만금이 갈라진 시점이기도 하다 | 4 — 만금표국 · 만금전장 · 용문표국 · (강호 전반) | 만금 둘의 개요 |
| **무림맹이 마지막으로 결성·해체된 일** | 3+ — 사도련 · (무림맹) · 정파 전체 | 사도련 개요 · `canon/세력목록.md` 미결 |
| **천자의 예가 끊긴 일** | 2 — 태산파 · (관·조정) | 태산 개요 · 미결 |
| **밖에서 온 가르침을 쓸어낸 일** | 2 — 배화교 · (관) | 배화교 개요 |
| **혈교가 천마신교에서 갈라진 일** — 홍양겁 성립 이후 | 3 — 천마신교 · 혈교 · (소림사) | 혈교 갈라져 나온 자리 |
| **사방(蛇幇)이 갈라진 일** | 2 — 흑사방 · 백사방 | 양쪽 개요 · 양쪽 미결 |
| **숭산의 넷이 소실로 넘어간 일** | 2 — 숭산파 · 소림사 | 숭산 개요 (소림 문서에는 없다) |
| **형산 절 쪽 문하가 끊긴 일** | 1 — 형산파 | 끊긴 쪽 · 미결 |
| **종남이 비다시피 했던 시절** | 1 — 종남파 | 개요 · 미결 |
| **연(燕)이 서고 망한 일** | 1 — 모용세가 | 개요 |
| **흑풍채 아래 새 길이 난 일** | 2 — 흑풍채 · (녹림맹) | 개요 · 미결 |
| **노첩이 넘어간 일** | 1 — 용문표국 | 기술 절 · 미결 |
| **녹림산에서 굶주린 자들이 일어난 일** | 1+ — 녹림맹 · (녹림 계열 전체) | 개요 |

### 후보의 성격이 셋으로 갈린다

| 성격 | 후보 | 특징 |
|---|---|---|
| **강호 바깥에서 온 것** | 관이 끊은 일 · 천자의 예 · 쓸어냄 · 연의 흥망 · 새 길 | 세력이 어찌할 수 없었고, 전부 「그 뒤로 줄었다」로 이어진다 |
| **강호 안에서 갈라진 것** | 혈교 · 사방 · 만금 · 무림맹 · 문파 분열 다섯 | 상대 순서는 있으나 절대 시점이 하나도 없다 |
| **끊기거나 넘어간 것** | 형산 절 쪽 · 숭산의 넷 · 종남이 빈 시절 · 노첩 | **전부 「언제인지 모른다」로 끝난다.** 연표가 서야 답이 나온다 |

> **가장 많은 문서가 걸린 것은 관(官) 쪽이다.** 그런데 관은 `canon`에서 보류다.
> 이 자리를 어떻게 다룰지가 연표 작업의 첫 결정이 된다. **여기서 정하지 않는다.**
