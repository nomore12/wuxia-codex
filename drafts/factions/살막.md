# 살막 (殺幕)

## 개요

살막을 겪은 자는 적지 않다. 다만 겪은 자마다 다른 것을 겪었다.

누구는 사흘을 따라붙던 자를 보았다 하고, 누구는 문 앞에서 잠깐 스친 얼굴을 말하며, 누구는 아무도 보지 못한 채 사람만 잃었다. 이 증언들을 나란히 놓으면 서로 맞지 않는다. **그래서 살막에 관해 밖에 쌓인 것은 조각뿐이며, 조각이 맞춰지지 않는다.**

**살막은 한 사람이 일을 끝내지 않기 때문이다.** 표적을 찾는 자와 실제로 드는 자와 뒷일을 지우는 자가 따로 있고, 셋이 서로 얼굴을 모르는 경우도 있다. 겪은 자는 그중 하나만 겪었으므로 제가 본 것이 살막의 전부라고 여기며, 그 말들이 모여도 하나로 서지 않는다.

**무공도 같은 방식으로 나뉘어 있다.** 살막의 문하는 제 자리에 필요한 것만 익힌다. 찾는 자는 엎드려 기다리는 법을 익히고 드는 자는 짧은 것을 쓰는 법을 익히며, 서로의 것을 배우지 않는다. 아래 목록은 세 자리의 것을 한자리에 모은 것이다. **누구도 이 전부를 익히지 않으며, 익힐 까닭도 없다.** 살막의 무공이 알려져도 곤란하지 않은 까닭이 여기 있다 — 누가 무엇을 익혔는지를 모르면 알아도 대비할 수 없다.

### 사도련에 들지 않는다

살막은 값을 받고 일한다. 값을 내는 자가 사도련 안에도 있고 밖에도 있으므로, 련에 들면 편이 생긴다. 편이 생기면 한쪽의 값을 받지 못한다.

련에서 몇 차례 청한 일이 있었다고 하나 살막이 무엇이라 답했는지는 전하지 않는다.

## 맡은 자리

**살막을 나누는 축이다.** 표마다 붙은 「자리」 열은 아래 셋 중 하나를 가리킨다.

| 표시         | 뜻                                    |
| ------------ | ------------------------------------- |
| **찾는 자**  | 표적을 좇고 때를 고른다               |
| **드는 자**  | 실제로 손을 쓴다                      |
| **지우는 자** | 뒷일을 치운다                        |
