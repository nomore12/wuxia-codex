# 작업 지시서

작성자가 AI에게 준 지시서를 남긴다.

**지시서는 대화에서 만들어져 붙여넣기로 전달된다.**
남기지 않으면 사라지므로, 작업이 끝난 뒤 작성자가 여기에 저장한다.

## 왜 남기는가

- 같은 작업을 다시 할 때 재사용한다
- 3차·4차에서 「1차 때 어떻게 지시했는지」를 참고한다
- 어떤 지시가 잘 먹혔고 어떤 지시가 오해를 샀는지가 남는다

## 파일명

`{날짜}_{대상}_{작업}.md`

```
2026-08-25_소림사_1차.md
2026-09-02_전체_내부불일치정리.md
2026-09-03_저장소현황_갱신.md
```

## 머리에 적을 것

```yaml
---
date: 2026-09-03
tool: codex          # opus | codex | gemini
target: drafts/저장소현황.md
result: 완료         # 완료 | 부분 | 반려
commit: 55333fd
---
```

`result`가 「부분」이나 「반려」면 **왜 그랬는지 한 줄 적는다.**
지시가 부정확했던 경우가 특히 값이 있다.
