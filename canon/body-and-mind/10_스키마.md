## 10. 스키마

### 인물

```yaml
sim:
  depth: 6              # 심의 깊이 (순수한 양)
  simbeop: jaha_singong
  nature: 강직          # 타고난 성격
  fit: null             # 성격-심법 합치. 계산 방식 미확정(§11). 임의로 값을 넣지 말 것
  drift: null           # 어긋남이 생겼다면 그 내용
  misread: false        # 오독 여부 (§4)
  trials: []            # [선택] 마음을 흔든 사건들 (§2)

che:
  depth: 4              # 체의 깊이 (순수한 양)
  constitution: 완력형   # 타고난 체질

imbalance: null         # null | sim_heavy | che_heavy. 구간 비교로 판정 (아래 참조)

dominance: sim          # sim | che | mugong. 세 톱니 중 무엇이 지배적인가 (§5)
dominance_cause: >      # 왜 그런가. dominance를 적었다면 반드시 함께 적는다
  열둘에 다리를 잃고 십 년을 앉아서만 수련했다.
  몸이 자랄 시기를 놓쳤으므로 마음이 앞섰다.

known_to_world: false   # 강호에 알려졌는가
reputed:                # 세간이 알고 있는 것. 실제와 다를 수 있다
  sim_depth: 4
  che_depth: 4

risk:
  type: null            # 역행 | 탈신 | 폭주

byeolho:
  name: 발산삼검
  given_by: 강호        # 강호 | 문파 | 적
  origin_event: event_xxxx
  accuracy: 과대        # 정확 | 과대 | 과소 | 시대착오
```

### 무공

```yaml
mugong:
  name: 이십사수매화검법
  kind: 검법            # 검법·도법·권법·장법·지법·보법·경공·암기술·외공 등
  group: null           # [선택] 문파 안에서 이 무공이 묶이는 총칭
  supported_by: [자하신공]
  choshik: []           # 초식. 1차 작업에서는 비워둔다
  jeolgi: []            # 절기. composed_of로 초식을 참조한다
```

#### `group` — 총칭

**`kind`와 `group`은 다른 층이다.**

- `kind`는 그 무공이 **무엇을 쓰는가**다. 검법인가 권법인가.
- `group`은 그 문파 안에서 **무엇으로 묶이는가**다.

하나의 `group`이 여러 `kind`에 걸칠 수 있다.

| 예 | kind | group |
|---|---|---|
| 일지선공 | 지법 | 칠십이절기 |
| 철포삼 | 외공 | 칠십이절기 |
| 벽호유장술 | 경공 | 칠십이절기 |
| 나한권 | 권법 | 나한 |
| 나한곤 | 곤법 | 나한 |
| 나한진 | 진법 | 나한 |

- **`group`은 선택이다.** 묶이지 않는 무공이 대다수다.
- 심법에도 쓸 수 있다. 소림의 오정심관이 그 예다.
- **총칭을 `kind` 자리에 쓰지 않는다.** 그렇게 하면 4차에서 kind를 붙일 때
  묶음이 사라지거나, 세력 간 대조가 깨진다.
- 총칭 자체가 하나의 무공이기도 한 경우(예: 오정심관)는
  그 항목의 `group`을 비우고, 아래 딸린 것들이 그 이름을 `group`으로 갖는다.

### 사건 (event)

`byeolho.origin_event`와 `trials[].event`가 참조하는 대상이다.

```yaml
event:
  id: event_1147_seolryeong    # event_{연도}_{장소 또는 약칭}
  name: 설령의 변
  year: 1147                   # 무림력
  place: 설령
  what: >
    한두 줄 요약.
  involved: []                 # 인물 id
  sects: []                    # 세력 id
```

- **id 형식은 `event_{연도}_{장소 또는 약칭}`으로 고정한다.**
- 참조된 사건은 반드시 실재해야 한다. 존재하지 않는 id를 참조하지 않는다.
- 연표 앵커에 해당하는 사건은 별도 표시한다. (앵커 목록 미작성 — §11)

### 인물을 정의하는 세 층

```
타고난 것 : 성격, 체질
익힌 것   : 심법, 무공
도달한 것 : 심 깊이, 체 깊이
```

**이 세 층이 어긋나는 방식이 곧 그 인물의 문제이자 이야기다.**

### `dominance` 사용 원칙

`dominance`는 **검증 항목이 아니라 작성 장치다.**

- 인물 설정은 AI에게 전적으로 맡기지 않는다. 작성자가 방향을 지정한다.
- 세력 문서에 이름만 등장하는 인물에게는 붙이지 않는다.
- **붙였다면 `dominance_cause`를 반드시 함께 적는다.**
  "그냥 그런 사람"은 인물이 아니다. 그렇게 된 내력이 있어야 한다.
- 이 칸을 채우는 것만으로 인물이 선명해진다. `trials`와 같은 원리다.

### `trials` 사용 원칙

`trials`는 **선택 필드**다. 모든 인물에게 채우지 않는다.

- 세력 문서에 이름만 등장하는 인물에게는 붙이지 않는다.
- **실제로 글에 등장하는 인물에게만** 붙인다.
- 성격을 형용사로 적는 대신 **겪은 일을 적는 장치**다.
  "냉정하고 과묵함"이 아니라 "스무 살에 사형 셋을 한 번에 잃음"으로 쓴다.

```yaml
trials:
  - event: event_1147_seolryeong
    what: 사형 셋을 한 번에 잃음
    age: 20
    shook: [평정]        # 어떤 마음이 흔들렸는가
```

### 검증 규칙

#### `breaks_on`의 소유 위치

**`breaks_on`은 심법의 속성이다. 인물의 속성이 아니다.**

- 인물에게 `breaks_on` 필드를 두지 않는다.
- 인물의 금기 감정은 **그가 익힌 심법의 `breaks_on`을 참조**해서 얻는다.
- 따라서 같은 심법을 익힌 자는 같은 금기를 갖는다.
  (인물마다 다른 금기를 두려면 별개의 심법으로 분리한다)

#### `imbalance` 판정

**수치를 빼지 않는다.** §1의 구간으로만 비교한다.

```
구간: [0] [1–2] [3–5] [6–7] [8–9] [10]
```

- 심과 체가 **같은 구간**이면 `null`
- **한 구간** 차이면 `null` (흔한 일이다)
- **두 구간 이상** 벌어지면 `sim_heavy` 또는 `che_heavy`

#### 규칙 목록

- `fit`은 직접 입력하지 않는다. `nature`와 심법의 `traits`에서 계산한다.
  단 **계산 방식이 미확정(§11)이므로, 현재 단계에서는 `null`로 둔다.**
- 모든 심법 문서에 `traits`와 `breaks_on`이 있어야 한다.
- **depth가 심·체 모두 5 이하인 인물에게 `risk`를 부여하지 않는다.**
  문턱(5→6) 이하에서는 주화입마가 발생하지 않는다.
- `imbalance`가 `null`이 아니고 어느 한쪽이 6 이상이면 `risk` 필수.
- 체·심 양쪽 모두 최고 구간인 인물은 두지 않는다.
  (AI 생성 시 반드시 시도되는 패턴이므로 반드시 차단할 것)
- `jeolgi[].composed_of`는 같은 무공의 `choshik`에 존재하는 것만 참조한다.
- `group`을 `kind` 자리에 쓰지 않는다. 총칭은 kind가 아니다.
- 한 세력 안에서 같은 `group`을 갖는 항목이 하나뿐이면 `group`을 비운다.
  묶이지 않은 것을 묶었다고 표시하지 않는다.
- `byeolho`에는 `origin_event`가 있어야 한다. 사연 없는 별호를 만들지 않는다.
- 무공의 `supported_by`와 사용자의 `sim.simbeop`이 불일치하면 `drift` 누적을 기록한다.
  (단 `drift`의 진행 규칙은 미확정 — §11)
- **[보류] 심법의 지향이 다른 인물 간 강함 비교 서술 금지.**
  → 지향 체계 자체가 미확정(§11)이므로 확정 전까지 이 규칙은 적용하지 않는다.
